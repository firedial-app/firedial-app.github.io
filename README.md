# firedial-app.github.io

Homepage and privacy policy for [FireDial](https://github.com/sebastianstucke87/FireDial), served at https://firedial-app.github.io.

## Build

Nothing to build.

## Install

GitHub Pages serves `main` from the repo root.

## Usage

Edit `index.html` or `privacy.html` and push to `main`. Keep `privacy.html` identical to FireDial's `PRIVACY.md`.
